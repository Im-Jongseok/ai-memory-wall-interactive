# AI and Memory Wall · 인터랙티브 논문 리뷰

`dist/index.html`을 브라우저에서 열면 실행됩니다. 인터넷 연결이나 설치가 필요하지 않습니다. `dist` 폴더 전체를 함께 보관하세요.

상위 폴더의 `AI_and_Memory_Wall_인터랙티브.html`은 이미지와 코드를 내장한 단일 파일입니다. 이 파일만 복사해서 오프라인 발표할 수도 있습니다. `python3 build_standalone.py`로 다시 생성합니다.

원문: 제공된 IEEE Micro 출판본, 44(3), pp. 33–39, May/June 2024. DOI: 10.1109/MM.2024.3373763.

- `←` / `→` 또는 `Space`: 발표 진행
- `O`: 원문 전체와 선택한 그림·문단 확대 전환
- `T`: 해석을 접고 원문만 크게 보기
- `N`: 발표자 노트
- `M`: 원문 페이지 탐색
- `F`: 전체 화면
- 원문 위 휠: 확대·축소 / 드래그: 이동 / `⌖`: 현재 장면 맞춤

화면 내 `?` 버튼에도 단축키가 있습니다. 모바일에서는 아래로 스크롤해 해석을 볼 수 있습니다.

내용은 `dist/content.js`, 동작은 `dist/app.js`, 디자인은 `dist/style.css`에서 수정합니다. 원문 이미지와 제공된 PDF는 `dist/assets/`에 있습니다.

그래프를 다시 그리지 않고 출판본 페이지 이미지를 확대합니다. 한글 해석과 발표자의 평가는 원문과 구분해 표시했습니다. Fig. 3의 지연시간은 BERT-Base 입력 길이 128 기준의 정규화 값이며, CPU·batch 1 조건의 관측입니다.
