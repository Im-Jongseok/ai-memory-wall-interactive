# AI and Memory Wall · 인터랙티브 논문 리뷰

`dist/index.html`을 브라우저에서 열면 실행됩니다. 인터넷 연결이나 설치가 필요하지 않습니다. `dist` 폴더 전체를 함께 보관하세요.

상위 폴더의 `AI_and_Memory_Wall_인터랙티브.html`은 이미지와 코드를 내장한 단일 파일입니다. 이 파일만 복사해서 오프라인 발표할 수도 있습니다. `python3 build_standalone.py`로 다시 생성합니다.

원문: 제공된 IEEE Micro 출판본, 44(3), pp. 33–39, May/June 2024. DOI: 10.1109/MM.2024.3373763.

- `←` / `→`, `↑` / `↓` 또는 `Space`: 발표 진행
- `O`: 원문 전체와 선택한 그림·문단 확대 전환
- `T`: 해석을 접고 원문만 크게 보기
- `N`: 발표자 노트
- `M`: 원문 페이지 탐색
- `F`: 전체 화면
- 원문 위 휠·드래그: 이동 / `Ctrl`+휠: 확대·축소 / `0`: 현재 장면 맞춤

`H`를 누르면 단축키 안내를 볼 수 있습니다. 모바일에서는 아래로 스크롤해 해석을 볼 수 있습니다.

첫 장면은 별도 표지 없이 IEEE 출판본의 제목·저자·초록이 있는 위쪽을 크게 보여 줍니다. 첫 페이지의 세 장면은 같은 배율을 유지하고 제목·저자 소개 → 초록 → 아래쪽 Introduction 본문으로 내려갑니다. 페이지 전체 이미지는 유지하며, 강조할 영역 이외의 원문은 블러 처리합니다.

발표 순서는 필요한 그림·문단만 확대하는 23개 장면입니다. 페이지가 바뀌어도 전체 페이지를 먼저 보여 주지 않고 대상 영역으로 바로 들어갑니다. Fig. 2의 두 패널도 각각 확대합니다. 전체 원문은 `O` 또는 `M`으로 직접 선택했을 때만 표시합니다. 삭제한 안내 장면의 기존 링크는 해당 확대 장면으로 이동합니다.

흰 배경에 상단 전체 화면 버튼과 하단 원형 화살표 버튼 두 개만 남겼습니다. 원문 주위의 별도 패널, 도구 모음, 페이지 표시, 미니맵과 출처 줄을 제거했고 제목·설명은 오른쪽에만 표시합니다.

설명 글씨는 원문과 맞춰 검정·회색 본문과 IEEE 파란색의 작은 섹션 표기를 사용합니다.

내용은 `dist/content.js`, 동작은 `dist/app.js`, 디자인은 `dist/style.css`에서 수정합니다. 원문 이미지와 제공된 PDF는 `dist/assets/`에 있습니다.

그래프를 다시 그리지 않고 출판본 페이지 이미지를 확대합니다. 한글 해석과 발표자의 평가는 원문과 구분해 표시했습니다. Fig. 3의 지연시간은 BERT-Base 입력 길이 128 기준의 정규화 값이며, CPU·batch 1 조건의 관측입니다.
